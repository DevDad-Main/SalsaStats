    Frame analysis

    Optional PresentMon fields. Click-to-photon is measured in the game session and does not include GeForce NOW network or client-display latency. CPU/GPU limit is a heuristic.

    GeForce NOW stream

    Read from the NVIDIA streamer log on the cloud PC, so these describe the session as the cloud PC sees it. NVIDIA stops writing the round trip and score lines after roughly 35 minutes, so those readings are only live early in a session and are hidden once they go stale (Round trip then shows its last known value and age for 10 minutes). Codec, resolution and client details are written once and stay. Packet and frame loss counts, Wi-Fi details and live ping are measured on your own device and cannot be read from here. Only shown during a GeForce NOW session.

    Keybinds

    The overlay ignores the mouse, so use these while playing. Click a key combination to change it.

      Startup and overlay

      SalsaNOW sessions start from a clean Windows each time, so "Start with Windows" does not carry over. This option adds SalsaStats to SalsaNOW's own startup batch file instead, without touching anything else in it.

      With the last option the overlay stays hidden until a game starts presenting frames, and hides again about 20 seconds after it stops. Ctrl+Alt+H still hides or shows it by hand. Start with Windows only works in the installed app.

      Frame rate

      This only caps the FPS values shown by SalsaStats to help compare with your stream rate. It does not limit the game or change the GeForce NOW stream.

      Window behavior

      Keeps the overlay on the highest window level. Leave off if a game minimizes or closes.
