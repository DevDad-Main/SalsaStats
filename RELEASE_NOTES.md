# SalsaStats 1.0.26

## What's new

- Resize the overlay from any of its four corners in edit mode (Ctrl+Alt+E); the opposite corner stays in place and the text scales with the panel.
- Fix the overlay panel not growing when you add group spacing, and staying a thin strip after leaving the minimal view. The panel now keeps its natural height.
- No spacing above the first overlay group, so the GPU block sits at the top of the panel.
- New "Show border" option for the overlay, saved per layout.
- Redesigned game picker: clickable path bar, folder and game icons, and a selection list with Select all, None and a running count when adding every game in a folder.

## Install and update

Download `SalsaStats-1.0.26-x64-Setup.exe` and run it to install for the current user; administrator elevation is not requested.

The installer is unsigned. SmartScreen or managed-device application-control policies may still warn or block it.
