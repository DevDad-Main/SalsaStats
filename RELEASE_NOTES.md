# SalsaStats 1.0.27

## What's new

- The Updates card in Settings now shows the whole update: a progress bar while it downloads and a Restart to update button when it's ready. A check you start there no longer opens the top banner, while updates found automatically still do.
- The minimal view has its own appearance settings (text size, panel size, spacing, background and border), so tuning it no longer changes the detailed overlay. It is saved per game layout.
- Keybinds are now configurable in Settings: click a combination, press the new keys, or reset to the defaults.
- FPS, average and 1% low now line up with the other numbers in the overlay.
- Refreshed README.

## Install and update

Download `SalsaStats-1.0.27-x64-Setup.exe` and run it to install for the current user; administrator elevation is not requested.

The installer is unsigned. SmartScreen or managed-device application-control policies may still warn or block it.
