# SalsaStats 1.0.30

- Removed network ping, jitter, loss, and throughput readings, which did not represent GeForce NOW stream metrics.
- The overlay appearance preview now follows the panel-width setting and stays visible beside controls while scrolling.
- Restoring from fullscreen returns the window to its previous size and position.
- Scrollbars now use a slim, standalone pill style.

If 1.0.28 is installed it cannot start, so it cannot update itself. Download and run the 1.0.29 installer manually.
